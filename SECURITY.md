# Security Policy

See also `SECURITY_AND_PRIVACY.md` in this repository for application privacy notes.

## Reporting a vulnerability

Email **jon@simoneresearch.com** with a clear description of the issue and steps to reproduce. Please do not open a public GitHub issue for sensitive reports.

## Scope

This repository is research and tooling software from Simone Systems Research LLC (founder-led). There is no bug bounty and no claim of being a commercial security product.

## Response

Reports will be acknowledged when practical. Fixes ship on a best-effort basis.
